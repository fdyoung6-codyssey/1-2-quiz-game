# 🎯 나만의 퀴즈 게임

## 1. 프로젝트 개요

터미널에서 실행하는 **Python 콘솔 퀴즈 게임**입니다.
메뉴에서 번호를 선택해 퀴즈를 풀고, 새 퀴즈를 추가하고, 최고 점수를 확인할 수 있습니다.
퀴즈와 최고 점수는 `state.json` 파일에 저장되어 프로그램을 종료한 뒤 다시 실행해도 유지됩니다.

## 2. 퀴즈 주제와 선정 이유

- **주제:** Python · Git 기초
- **선정 이유:** 이번 미션에서 배우는 Python 문법(함수, 리스트, 클래스, 예외 처리)과
  Git 명령어(add, commit, push, pull 등)를 퀴즈로 풀어 보며 스스로 복습하기 위해 선택했습니다.

## 3. 실행 방법

### 개발 환경
- Python 3.10 이상
- 외부 라이브러리 없음 (표준 라이브러리 `json`, `os`만 사용)

### 실행
```bash
git clone https://github.com/fdyoung6-codyssey/1-2-quiz-game.git
cd 1-2-quiz-game
python main.py
```

## 4. 기능 목록

| 메뉴 | 기능 | 설명 |
|---|---|---|
| 1 | 퀴즈 풀기 | 저장된 퀴즈를 순서대로 출제하고 정답/오답과 최종 점수를 보여줌 |
| 2 | 퀴즈 추가 | 문제, 선택지 4개, 정답 번호를 입력받아 새 퀴즈 등록 후 파일에 저장 |
| 3 | 퀴즈 목록 | 등록된 퀴즈 문제를 번호와 함께 출력 |
| 4 | 점수 확인 | 최고 점수 출력 (퀴즈를 풀 때마다 비교해서 갱신) |
| 5 | 종료 | 데이터를 저장하고 프로그램 종료 |

### 입력 / 예외 처리
- 입력값 앞뒤 공백 제거 후 처리
- 숫자가 아닌 입력, 범위 밖 숫자, 빈 입력 → 안내 메시지 후 다시 입력
- `Ctrl+C`(KeyboardInterrupt), 입력 종료(EOFError) → 데이터 저장 후 안전하게 종료
- `state.json`이 없으면 기본 퀴즈로 시작, 손상되었으면 기본 퀴즈로 복구

## 5. 파일 구조

```
1-2-quiz-game/
├── main.py        # 프로그램 전체 코드 (Quiz, QuizGame 클래스)
├── state.json     # 퀴즈 목록과 최고 점수 저장 파일 (자동 생성)
├── README.md      # 프로젝트 설명서
└── .gitignore     # Git에 올리지 않을 파일 목록
```

### 클래스 구조

| 클래스 | 역할 | 주요 메서드 |
|---|---|---|
| `Quiz` | 퀴즈 한 문제 | `display()` 문제 출력, `is_correct()` 정답 확인, `to_dict()` 저장용 변환 |
| `QuizGame` | 게임 전체 관리 | `run()` 메뉴 실행, `play_quiz()`, `add_quiz()`, `show_quiz_list()`, `show_score()`, `load_data()`, `save_data()` |

## 6. 데이터 파일 설명 (state.json)

- **경로:** 프로젝트 루트 (`main.py`와 같은 폴더)
- **인코딩:** UTF-8
- **역할:** 퀴즈 목록과 최고 점수를 저장하여 프로그램을 다시 실행해도 데이터 유지
- **저장 시점:** 퀴즈 추가 후, 최고 점수 갱신 후, 프로그램 종료 시

### 필드 구조

| 키 | 형태 | 설명 |
|---|---|---|
| `quizzes` | 리스트 | 퀴즈 목록 |
| `quizzes[].question` | 문자열 | 문제 |
| `quizzes[].choices` | 문자열 4개 리스트 | 선택지 |
| `quizzes[].answer` | 정수 (1~4) | 정답 번호 |
| `best_score` | 정수 또는 null | 최고 점수 (100점 만점, 아직 풀지 않았으면 null) |

### 예시

```json
{
    "quizzes": [
        {
            "question": "Python에서 화면에 글자를 출력하는 함수는?",
            "choices": ["input()", "print()", "len()", "str()"],
            "answer": 2
        }
    ],
    "best_score": 100
}
```


## 7. Git 실습 기록

- `git clone`으로 저장소를 별도 폴더(1-2-quiz-game-clone)에 복제하여 README를 수정하고 push함
- 원래 작업 폴더에서 `git pull`로 변경사항을 가져와 반영을 확인함
